# PebTautulli

Monitor your Plex media server from your wrist. Tautulli for Pebble connects to your Tautulli instance and gives you a live view of everything happening on your server — all without reaching for your phone.

Now Playing
See every active stream at a glance. Each card shows who's watching, what they're watching, playback progress, player name, bandwidth, video and audio codec with transcode decision, and the geographic location of the stream. Refreshes automatically every 30 seconds.

History
Browse your full watch history with user, stream location, percentage watched, and duration. Tap any item for a detail view showing player, start/stop times, and transcode decision. Scroll through as many entries as you need with seamless pagination.

Recently Added
Stay on top of new content as it lands in your library. Tap any title for rich metadata — summary, cast, studio, genres, content rating, and runtime. Full summary text is scrollable so nothing gets cut off.

Features
- Live stream monitoring with geolocation (City, State, Country)
- Transcode vs direct play indicators for video and audio
- Bandwidth usage per stream
- Unlimited scroll pagination for History and Recently Added
- Scrolling subtitles on long text
- Configurable host, port, URL path prefix, and API key via in-app settings
- Works with self-hosted Tautulli behind a reverse proxy (HTTPS supported)

Setup
Open the app settings from the Rebble phone app, enter your Tautulli server address and API key, and you're ready to go. Find your API key under Tautulli → Settings → Web Interface.

Requires a running Tautulli instance. Compatible with Pebble Time 2.
